# 陈家祠导航规则——路径连接关系

> **数据来源**：广东民间工艺博物馆官网；2026-07-26用户提供新平面图校准

## 一、空间连接关系

### 中轴线连接

陈家祠的中轴线由南向北依次串联以下空间节点：

入口 → 前院 → 首进正厅 → 前庭 → 月台 → 聚贤堂 → 后庭 → 后进正厅（祖堂） → 后花园

这是陈家祠建筑群的主轴线，贯穿南北。

### 相邻节点连接关系

**前院与周边**：前院通过正门通道与首进正厅相连，通过侧门通道分别通往西侧的西门和东侧的东门。

**首进区域内部**：首进正厅通过侧门或连廊向东侧连通首进东厅，向西侧连通首进西厅。首进东厅与前东斋相邻，首进西厅与前西斋相邻。

**首进与前庭**：首进正厅通过中轴线通道向北连通前庭。前庭西侧与前西厢相邻，前庭东侧与前东厢相邻。

**前庭与中进**：前庭通过中轴线通道向北连通月台和聚贤堂。东西两侧的青云巷分别连接首进与中进。

**中进区域内部**：月台为聚贤堂前平台，通过台阶或平台与聚贤堂相连。聚贤堂通过侧门或连廊向东侧连通中进东厅，向西侧连通中进西厅。中东厢位于中进东厅区域内（非独立建筑），中西厢位于中进西厅区域内（非独立建筑）。

**中进与后庭**：中进通过中轴线通道向北连通后庭。后庭西侧与后西厢相邻，后庭东侧与后东厢相邻。东西两侧的青云巷分别连接中进与后进。

**后庭与后进**：后庭通过中轴线通道向北连通后进正厅。

**后进区域内部**：后进正厅通过侧门或连廊向东侧连通后进东厅，向西侧连通后进西厅。后进东厅与后东斋相邻，后进西厅与后西斋相邻。后进正厅通过正门通道与后花园相连。

**走廊与设施**：西走廊位于后西厢西侧，从后西厢旁门出去即到，洗手间位于西走廊内。东走廊位于后东厢东侧，从后东厢旁门出去即到，办公室位于东走廊内。

### 东西路连接线

**东路连接线**（由外到内）：东门 → 前东斋 → 首进东厅 → 青云巷 → 中进东厅 → 青云巷 → 后进东厅 → 后东斋 → 后东厢旁门 → 东走廊 → 办公室

**西路连接线**（由外到内）：西门 → 前西斋 → 首进西厅 → 青云巷 → 中进西厅 → 青云巷 → 后进西厅 → 后西斋 → 后西厢旁门 → 西走廊 → 洗手间

## 三、空间特征说明

### 青云巷

青云巷位于各进之间的西厅与中厅、中厅与东厅之间，连通南北，从而连通前、中、后进。

**主要功能**：
1. 连接各进建筑的通道
2. 通风采光
3. 防火隔离带
4. 空间分隔

**特征**：顶棚从里面看为卷棚顶，从外面看有屋脊，屋脊上同样有灰塑和陶塑装饰。青云巷两侧墙上的砖雕装饰精美，是近距离欣赏砖雕艺术的最佳位置。

### 连廊

连廊位于各厅堂、厢房之间，具有交通通道、避雨遮阳以及观赏休憩三项主要功能。连廊共有八条长廊，与各单体建筑互相穿插，形成丰富的空间层次。另有资料记载为4条青云廊（即连廊），分布在东西两路，连接各建筑单体。

### 庭院

陈家祠共有六处庭院（包括前院、前庭、后庭、后花园等），具有采光通风、景观休憩和空间过渡的功能。庭院空间开阔，与厅堂的封闭空间形成对比，是建筑群中"虚实相间"的重要体现。

### 聚贤堂

聚贤堂是全祠核心建筑，位于中进中轴线上，堂宇轩昂，庭院宽敞，梁架雕镂精细，面积达287平方米，是全祠最大的展厅。聚贤堂正脊装饰着长27米、全高4.2米的石湾陶塑脊饰，是已知岭南祠堂建筑中最大、最繁复的脊饰，由清代石湾陶塑商号「文如璧」制作。堂前有一座宽阔的白石露台（即月台），月台周围用嵌有铁铸通花栏板的石雕栏杆环绕。

### 前庭与后庭

- **前庭**：位于首进正厅北侧、中进聚贤堂南侧，是首进与中进之间的过渡庭院。前庭西侧为前西厢，前庭东侧为前东厢。
- **后庭**：位于中进与后进之间，是中进与后进的过渡庭院。后庭西侧为后西厢，后庭东侧为后东厢。

### 西走廊与东走廊

- **西走廊**：位于后西厢西侧（建筑群西侧外围），从后西厢旁门出去即到，洗手间即位于此走廊内。门在南北方向上与前后西厢在同一直线上，在东西方向上与中进西厅、聚贤堂、中进东厅在同一直线上。
- **东走廊**：位于后东厢东侧（建筑群东侧外围），从后东厢旁门出去即到，办公室即位于此走廊内。与西走廊对称分布。
