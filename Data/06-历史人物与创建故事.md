# 06 - 历史人物与创建故事

---

## 一、陈家祠创建的真正推动者

学界传统观点认为陈家祠由探花陈伯陶、驻美公使陈兰彬等48位士绅发起创建。但近年来的田野调查、香港档案与史料研究揭示：**真正的创建人是两位来自新会的香港商人**。

---

## 二、关键人物档案

### 1. 陈瑞南（陈桂士）—— 第一倡建人

| 项目 | 内容 |
|------|------|
| 本名 | 陈桂士，字瑞南 |
| 籍贯 | 广东新会潮连乡 |
| 身份 | 瑞记洋行（Arnhold, Karberg & Co.）买办 |
| 社会角色 | 香港东华医院、广州爱育善堂创始人 |
| 官衔 | 捐纳候选道（虚衔） |
| 家庭 | 陈昭常的伯父 |

**事迹：**
- 1860年起担任德国在华最大企业瑞记洋行买办
- 因洋行工作及慈善事业需要，在香港、广州两地穿梭
- 1871年参与发起广州爱育善堂，多年负责抢险赈灾
- 1873年与梁云汉、冯明珊设立中华印务总局，创办第一张华人自主经营的报纸《循环日报》
- 1876年被陈兰彬提名随同赴美（后因两广总督刘坤一奏留未成行）
- **1888年，发起创建陈家祠**，是真正意义上的第一倡建人
- 利用士绅名望作号召，实际由他主导筹建工作
- 1889年侄子陈昭常考中举人，1894年考中进士，极大鼓舞了集资活动

### 2. 陈照南（陈棨熙）—— 实际主持筹建人

| 项目 | 内容 |
|------|------|
| 本名 | 陈棨熙，号照南 |
| 籍贯 | 广东新会 |
| 身份 | 香港怡南号建造行东主（建筑商） |
| 官衔 | 拥有"同知衔"（捐纳虚衔） |
| 专业 | 建筑工程 |

**事迹：**
- 香港建筑商，也是**黄埔国防炮台的设计师和承建商**
- 陈家祠整个筹建工作的**全面主持人**
- 负责总体规划、基础工程设计
- 表面上有48位"绅耆"出名发起，实际上他是幕后核心人物
- 拥有建筑工程专业背景，确保了陈家祠建筑品质

### 3. 陈伯陶 —— 探花旗杆的"代言人"

| 项目 | 内容 |
|------|------|
| 本名 | 陈伯陶（1855-1930） |
| 字号 | 号象华，一字子砺 |
| 籍贯 | 东莞中堂凤涌 |
| 功名 | 1879年广东乡试解元（第一名举人），**1892年高中探花** |
| 官职 | 江宁提学使 |
| 其他身份 | 暨南大学创始人之一 |

**与陈家祠的关系：**
- 1888年在公启上列名，是陈家祠创建者用来宣传的"生招牌"
- 1892年高中探花时，陈家祠建设进行到一半，立即在门前竖起探花旗杆（四斗），用作进一步集资号召
- 许多陈氏族人认为陈家祠是由陈伯陶"提倡"创办的
- 但其诗文集《瓜庐文剩》《瓜庐诗剩》《陈文良公集》中**无一字提及陈家祠**
- 这种"冷遇"暗示他与实际主持人之间可能存在分歧

### 4. 陈兰彬 —— 挂名倡建的驻美公使

| 项目 | 内容 |
|------|------|
| 身份 | 中国第一位驻美公使 |
| 官职 | 左副都御史（京官正三品） |
| 籍贯 | 广东吴川 |

**与陈家祠的关系：**
- 在《倡建绅耆芳名列》中排第19位（与其官职地位不符）
- 1888年倡议时，陈兰彬在吴川乡下养病，未到广州
- 传世联语极多，给广东14处陈氏祠堂题写过25副对联，但**从未给陈家祠题匾题联**
- 1888年列名应是陈瑞南力邀的结果

### 5. 陈昌潮 —— 挂名第一的宿儒

| 项目 | 内容 |
|------|------|
| 籍贯 | 广东番禺 |
| 身份 | 惠州府学训导、越华书院监院 |
| 排行 | 《芳名列》第一位 |
| 儿子 | 陈庆桂（1880年进士，排第30位） |

**与陈家祠的关系：**
- 在倡建绅耆中名列第一，因其主持越华书院（省级书院），地位崇高
- 但其墓表中**绝口不提**领衔创建陈家祠一事
- 极可能只是挂名，或与实际主持人存在重大分歧

### 6. 陈昭常 —— 进士旗杆的主人

| 项目 | 内容 |
|------|------|
| 身份 | 陈瑞南的侄子 |
| 功名 | 1889年中举人，**1894年中进士** |
| 官职 | 清末吉林巡抚 |

**与陈家祠的关系：**
- 7岁时父亲去世，由伯父陈瑞南抚养
- 他的进士旗杆（三斗）与陈伯陶的探花旗杆（四斗）共同竖立于陈家祠广场
- 考中进士与陈家祠落成几乎同期（1894年）

## 三、创建过程揭秘

### 为什么建合族祠？
- 清光绪年间，陈姓已是广东最大的姓氏，民间有"天下李，广东陈"的俗谚
- 广州城内一房难求，来省城办事的宗族子弟缺乏落脚地
- 各姓族人组织同姓宗亲在广州兴建祠堂式建筑
- 与普通宗族祠堂不同，由数县或数十县同一姓氏的群体合资捐建，故称"合族祠"

### 为什么叫"陈氏书院"？
- 清乾隆中期开始，官府因合族祠"把持讼事，挟众抗官"而大规模禁祠
- 各姓合族祠纷纷改名"书院""试馆""书室"以规避禁令
- 陈家祠挂"陈氏书院"匾额，实为挂书院之名、行祠堂之实

### 创建过程的"出口转内销"
- 陈家祠的实际创建者是**香港商人**，而非本土士绅
- 利用士绅名望作号召，集资建设
- 士绅与实际主持者之间存在分歧
- 导致知名士绅几乎都没有给陈家祠留下墨宝
- 陈家祠在本地不吃香（"本地姜唔辣"），反而被外地游客重视
- 1926年上海世界书局《广州快览》将陈家祠列为"省垣有名之宏丽建筑"，而同期广州本土旅游指南均未提及

### 集资方式
- 以"陈颍川堂"与"陈世昌堂"名义收购土地（16宗交易，1888-1892年）
- 陈世昌堂是陈瑞南所属的潮连巷头次溪祖后裔堂号
- 捐款条件：可将祖先牌位放进陈家祠神龛中供奉
- 大量台山华侨也汇款支援

## 四、关于创建历史的思考

陈家祠创建史并非单纯的建筑史，更是一部折射香港华人精英对科举文化、宗族文化、本土建筑文化"回归"的社会学课题。以下是值得思考的角度：

1. **商人主导，士绅挂名**——真正推动者是在香港发家的商人，士绅只是利用其名望
2. **"本地姜唔辣"**——在本地不受重视，反而在外地声名鹊起
3. **合族祠的灰色地带**——在官府禁祠令下以"书院"名义存在
4. **中西交融的印记**——墀头砖雕中出现了"小天使"等西方元素
