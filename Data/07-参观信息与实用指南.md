# 07 - 参观信息与实用指南

---

## 一、基本信息

| 项目 | 内容 |
|------|------|
| 正式名称 | 广东民间工艺博物馆（陈家祠 / 陈氏书院） |
| 地址 | 广州市荔湾区中山七路恩龙里34号 |
| 景区级别 | 国家AAAA级旅游景区（2008年） |
| 博物馆级别 | 国家一级博物馆（2017年） |
| 文保级别 | 全国重点文物保护单位（1988年） |

---

## 二、开放时间

- **开放时间**：每日 9:00 — 17:30
- **停止售票**：17:00
- **开始清场**：17:15
- **闭馆日**：**每周二闭馆**（法定节假日除外）
  - 另：每月最后一周的周一为闭馆检修日（如遇法定假日则顺延）
- **全年开放**：除闭馆日外

---

## 三、门票信息

- **门票价格**：**10元/人**
- **售票时间**：9:00 — 17:00

> 提示：部分平台提供私享人工讲解服务（含门票），价格较高（约424元起/不限人群）。但游客普遍反映不需要购买付费讲解，可在抖音等平台免费观看讲解视频。

## 四、交通方式

### 地铁（推荐）
- **广州地铁1号线** — 陈家祠站
- 从D出口出站步行约10米即可到达（地铁站就在陈家祠广场旁）

### 公交
- **268路**：起点中山八路总站，终点陈家祠总站（中山七路）
- 首末车时间：06:30 — 22:00
- 多条公交线路途经中山七路陈家祠站

### 自驾/出租车
- 导航至"广州市荔湾区中山七路陈家祠"
- 周边停车场有限，建议地铁出行

## 五、推荐游览路线

### 半小时快速路线
1. 首进正厅（双面镂空木雕大屏门、门神、铜铺首等）
2. 月台（石雕栏杆、铁铸通花栏板）
3. 中进聚贤堂
4. 后进中厅（百年陈家祠图片展）
5. 后进东厅（陈家祠建筑抢救性保护展）

### 一小时标准路线
1. **入口**：观赏大门石狮、石鼓、4米门神彩绘
2. **前院**：观看旗杆、了解整体布局
3. **首进**：木雕屏门、砖雕门楣
4. **首进庭院**：仰望屋顶陶塑脊饰
5. **青云巷**：细看砖雕、灰塑
6. **聚贤堂**：核心厅堂，27米陶塑瓦脊
7. **月台**：石雕栏杆、铁铸通花栏板
8. **中进东西厅**：各工艺展陈
9. **连廊**：欣赏廊下木雕、灰塑
10. **后进祖堂**：神龛、神案

### 两小时深度路线
在标准路线基础上增加：
- 在各庭院多角度观赏灰塑
- 细看26幅墀头砖雕
- 逐一辨认11条陶塑瓦脊的故事题材
- 参观各常设展览（象牙雕、广彩、剪纸等）
- 寻找"比耶小神仙"（日神）和18只瓦檐狮子

## 六、拍摄建议

| 拍摄对象 | 建议 |
|----------|------|
| 陶塑瓦脊 | 使用长焦镜头，从庭院仰拍 |
| 灰塑 | 注意光线角度，早晚光线更佳 |
| 砖雕 | 近距离拍摄，体现"挂线"精细 |
| 木雕屏门 | 使用广角镜头拍全景，再拍细节 |
| 门神 | 正面拍摄，注意不要使用闪光灯 |
| 石雕栏杆 | 侧光拍摄，凸显浮雕立体感 |
| 铁铸通花 | 利用逆光拍摄通透效果 |

---

## 七、实用提示

1. **最佳游览时间**：工作日上午9:00-11:00，游客较少
2. **建议时长**：1-2小时为佳
3. **穿着建议**：陈家祠以庭院为主，部分在室外，注意防晒防雨
4. **讲解方式**：可扫描景区二维码获取免费电子讲解，或提前了解资料自行游览
5. **周边景点**：上下九步行街（约1.5公里）、沙面（约2公里）、荔枝湾（约1公里）
6. **拍照注意**：室内展厅部分区域可能禁止使用闪光灯
7. **无障碍设施**：古建筑部分区域有门槛和台阶

## 八、"羊城八景"之"古祠留芳"

2002年，陈家祠以"古祠留芳"之名入选**新世纪羊城八景**，与白云山（云山叠翠）、珠江（珠水夜韵）、越秀山（越秀新晖）、中信广场（天河飘绢）、广东奥林匹克体育中心（五环晨曦）、黄花岗（黄花皓月）、莲花山（莲峰观海）并列。

2024年，陈家祠广场进行了复绿及景观改造工程，既保留了岭南文化的城市肌理，又与现代城市景观融合。
