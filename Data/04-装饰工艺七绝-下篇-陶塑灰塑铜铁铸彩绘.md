## 一、陶塑 —— 永不落幕的高空戏台

陈家祠的陶塑脊饰是其最具视觉冲击力的装饰，也是石湾陶塑艺术的巅峰代表。

### 基本数据
- 陈家祠共有**11条陶塑脊饰**瓦脊
- 瓦脊**总长度约156-163米**
- 刻画了**上千个故事人物**
- 分别由**文如璧、宝玉荣、美玉成、吴奇玉**等清代石湾名店制作
- 聚贤堂正脊上的陶塑瓦脊**长27米，全高4.2米**，为已知岭南祠堂建筑中最大、最繁复的脊饰

### 工艺特点
- 采用石湾陶泥塑造，经上釉和高温烧制
- 根据仰视角度，采用夸张手法追求大效果
- 双面人物脊，内容和色彩丰富多彩
- 历经百年风雨，釉彩依旧明艳

### 题材内容
以**历史故事和民间传说**为主：
- 以亭台、楼阁、石山作背景
- 用龙凤、博古花件和镶字花板等穿插相隔
- 加各种动物、花鸟、瓜果等图案点缀
- 多用民间熟悉的**粤剧折子戏场面**表现，通俗易懂

### 石湾陶塑背景
- 石湾（佛山）制陶史可追溯至新石器时代
- 唐代已现大型窑场，明清达鼎盛
- 清代屈大均《广东新语》："石湾之陶遍二广，旁及海外之国"
- 被称为"石湾公仔"，是国家级非物质文化遗产
- 截至2024年，当地有国家级陶艺大师27位、省级60位

## 二、灰塑 —— 岭南之冠的空中艺术

灰塑是珠江三角洲传统建筑中广泛运用的建筑装饰艺术，以石灰为主要材料，具有**会呼吸**的特性——能吸收和排放水汽、热量，适应岭南湿热气候。

### 基本数据
- 灰塑累计**总长2,562米**
- **总面积约2,448平方米**
- 规模之大为**岭南之冠**
- 平均高度约0.9米
- 分布在屋顶正脊、垂脊、屋檐、山墙、廊门、窗檐等处
- 拥有**18只瓦檐狮子**镇守檐角

### 工艺特点
- 以石灰为主要材料
- 构思精巧细腻，别致大方
- 能吸收和排放水汽、热量——"会呼吸"
- 解决建筑防热、防雨、防潮问题
- 需要定期保养维护（1980年代以来已进行**8次**灰塑保养维护工程）

### "比耶小神仙"与日神月神
- 陈家祠后东厅南面屋脊上有一尊灰塑人物像，被网友戏称为"比耶小神仙"
- 经考证，实为**中国传统神话中的日神**，左手原本应持象征太阳的铜镜
- 2025年第8次灰塑保养维护工程中，根据50多年前的历史照片恢复其"手持铜镜"的原状
- 对应位置的月神也计划恢复手握铜镜的原状

### 第8次灰塑保养维护工程（2025-2026）
- 维护面积：**1,285平方米**
- 由灰塑国家级代表性传承人**邵成村**（与灰塑结缘45年）主持
- 运用热成像探测、贴近摄影成像、倾斜摄影成像、三维建模等"黑科技"
- 维修案例：独角狮子的"CT检查"——发现腹部裂纹及内部钢筋锈蚀，通过三维模型原样复原

## 三、铜铁铸 —— 画龙点睛之笔

铜铁铸在陈家祠中用量不多，但起到了**画龙点睛**的作用。

### 工艺特点
- 将铁铸通花栏板镶嵌在石雕框架内
- 利用铁和石之间的色彩对比
- 铁铸的通透立体造型，使月台围栏产生如国画般的装饰效果

### 铁铸装饰
- 共**16块**铁铸装饰
- 分布在头门、聚贤堂前的月台和连廊中
- 题材包括"孔子问礼"等历史故事

## 四、彩绘壁画 —— 大门上的守护神

### 门神彩绘
陈家祠大门彩绘是其最具代表性的彩绘作品：

- 两扇黑漆大门上各绘一位门神，**高达4米**
- 是**广东地区现存最大的清代彩绘门神**
- 右侧（进门视角）：**红脸秦琼**，手持金瓜，神情刚毅，象征忠诚勇武
- 左侧（进门视角）：**黑脸尉迟恭**，手持钺斧（长斧），形象威严
- 两位门神出自唐代，传说有两位大将军守卫门户，能驱邪避灾
- 历经百年，人物面部表情依然生动，色彩依旧鲜艳

### 其他彩绘
- 大门门神之外的彩绘装饰使用不多，但作为七绝之一，在建筑细节中偶有呈现

|------|------|-----------|
| 三雕 | 木雕 | 数量最多、规模最大 |
| | 砖雕 | "挂线砖雕"，细如发丝 |
| | 石雕 | 花岗岩打造，坚固传世 |
| 二塑 | 陶塑 | 11条脊饰，163米，千余人物 |
| | 灰塑 | 总面积2,448平方米，岭南之冠 |
| 一铸 | 铜铁铸 | 16块铁铸，画龙点睛 |
