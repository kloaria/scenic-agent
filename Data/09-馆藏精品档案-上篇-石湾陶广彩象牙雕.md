## 一、石湾陶（馆藏 3,300+ 件/套）

广东民间工艺博物馆是国内收藏石湾陶器最多的博物馆之一，藏品釉色丰富、造型多样，涵盖明清至现当代名家名作。

---

### 藏品 #1：民国石湾窑「潘玉书制」青白釉贵妃醉酒陶摆件

| 项目 | 内容 |
|------|------|
| **名称** | 青白釉「贵妃醉酒」陶摆件 |
| **年代** | 民国（1912–1949） |
| **作者** | 潘玉书（1889–1938），名麟，字玉书，南海九江河清村人 |
| **尺寸** | 高 32 cm |
| **材质/工艺** | 陶胎，胎色灰白幼洁，双卷筒手捏原作；衣袍施青白釉，釉开纹片；面部素胎，眉眼发髻施石墨釉 |
| **底款** | 阳文方章「潘玉书制」 |
| **来源出处** | 广东民间工艺博物馆馆藏，具体入藏时间未公开；属博物馆早期征集所得 |
| **历史背景** | 潘玉书出身木雕手工艺人家庭，12 岁随父学木雕，14 岁暗地向黄炳学陶，后拜陈渭岩为师，兼学西洋雕塑技法。其作品被艺术界誉为「代表石湾陶塑发展方向的雕塑家」 |
| **相关故事** | **灌醉侍妾作模特**：潘玉书创作此件时屡易其稿，人物的醉态神韵难以把握。一天他约不会喝酒的爱妾廖少珍陪饮，爱妾醉后，潘玉书扶她入房时突然发现她斜靠着自己、步履轻浮不定的醉态，正是日夜寻觅的最佳神韵。他联想起白居易《长恨歌》「侍儿扶起娇无力」之句，立刻动手将此感受速塑出来，「贵妃醉酒」就此诞生。**来源：广州博物馆官网（guangzhoumuseum.cn）** |
| **艺术特色** | 人物体态丰腴典雅，人体比例准确；衣纹皱褶处理恰到好处，线条简练流畅，潇洒自然；造型灵感源自唐代周昉《簪花仕女图》和晚清任伯年人物画 |

### 藏品 #2：清代黄炳石湾陶系列（胎毛技法代表作）

| 项目 | 内容 |
|------|------|
| **名称** | 石湾窑黄炳陶塑系列（含禽鸟、猫等动物题材） |
| **年代** | 清代后期（约同治—光绪年间，1862–1908） |
| **作者** | 黄炳（约 1815–1894），石湾陶塑名家，同时也是国画家 |
| **材质/工艺** | 石湾本地红土混合黏土；独创「胎毛技法」——在陶坯八分干时，以特制竹刀一丝一缕雕出鸟兽羽翎皮毛，力求纤毫逼真 |
| **来源出处** | 广东民间工艺博物馆馆藏；部分为杨铨先生捐赠（1959–1964 年间，杨铨将 3,390 件古陶瓷捐给该馆，含大量石湾陶） |
| **历史背景** | 黄炳与其少叔黄古珍一起，吸取国画翎毛画法，创造了石湾陶塑「胎毛技法」，此技法一直应用至今。黄炳擅长书画，题材多为梅雀。**来源：广东省博物馆官网（gdmuseum.org.cn）、佛山日报** |
| **相关故事** | 黄炳的「金丝猫」系列（广东省博物馆所藏一件为其镇馆之宝）以胎毛技法刻出猫的根根毛发，四肢紧绷、瞠目而视的捕猎姿态，令人惊叹「以刀为笔、以土为纸」的写实功力。黄炳把宋元绘画中的翎毛画法移植到陶塑领域，使石湾动物陶塑达到前所未有的艺术高度。**来源：新华网广东频道（2025.5.20）** |

### 藏品 #3：刘传石湾陶塑系列（芭蕉罗汉、铁拐李、屈原等）

| 项目 | 内容 |
|------|------|
| **名称** | 刘传陶塑系列：《芭蕉罗汉》《铁拐李》《瘦骨仙》《屈原》《弃官寻母》《陆羽品茶》等 |
| **年代** | 20 世纪（刘传活跃于 1930 年代–2000 年） |
| **作者** | 刘传（1916–2001），又名刘永传，别署「湾溪刘传」，祖籍顺德，生于石湾陶工之家 |
| **尺寸** | 各异（《屈原》高达 2 米，为北京历史博物馆创作） |
| **来源出处** | 广东民间工艺博物馆馆藏多件刘传作品；《芭蕉罗汉》《铁拐李》《瘦骨仙》曾参展英国伦敦世界博览会；《李时珍采药》藏于中国工艺美术馆；《屈原》藏于北京历史博物馆（今中国国家博物馆）；《海瑞》置于北京人民大会堂广东厅 |
| **历史背景** | 1979 年被轻工部授予第一届「中国工艺美术家」（后改「中国工艺美术大师」）称号，是获此称号的第一位石湾陶艺家。在泥塑界有「北张南刘」之说——「北张」即泥人张张景祜，「南刘」即刘传。1961 年应中央美术学院之邀讲学，是第一位站上央美讲坛的石湾陶艺家 |
| **相关故事** | **12 岁当童工「窥师」学艺**：刘传因家贫 12 岁入「公仔行」当童工。他利用给师傅倒水的机会「偷师」，久而久之练就过目不忘的本领。**为创作《陆羽品茶》，让妻子穿上仿古衣服当模特**以观察衣纹走向。他总结出「宜起不宜止，宜藏不宜露」「十清一浊，十浊一清」「丑而不陋、奇而不怪」等经典艺术理论。**来源：羊城晚报（2023.3.8）、文史广东（gdwsw.gov.cn）** |
| **遗作** | 2000 年病逝时留下未完成的遗作《醉卧景阳冈》 |

### 藏品 #4：石湾窑祖唐居款黄釉兽头耳三足炉

| 项目 | 内容 |
|------|------|
| **名称** | 石湾窑黄釉兽头耳三足炉 |
| **年代** | 明末清初（祖唐居活跃于明晚期至清初） |
| **作者/店号** | 「祖唐居」——石湾著名陶艺店号 |
| **尺寸** | 不详（待补充） |
| **材质/工艺** | 炉腹圆鼓，腹部两侧附贴狮形铺首，三足；器身施黄釉，炉内和底部施赭色釉；底钤椭圆「祖唐居」印款 |
| **来源出处** | 广东民间工艺博物馆馆藏，编号可见于博物馆官网藏品数据库（www.gzcjc.com.cn） |
| **历史背景** | 「祖唐居」是石湾明末清初著名的陶艺店号，与「南石堂」「粤彩正记」等并称石湾名店。其作品以仿古器形和独特的黄釉著称，体现了石湾窑「广钧」釉色风格 |
| **相关故事** | 祖唐居、南石堂等名店号的作品是石湾窑商业化生产的代表。这些店号接受各地定制，产品远销东南亚。杨铨先生大量收藏此类石湾窑名店作品，后整体捐赠博物馆，构成了该馆石湾陶藏品的重要基础。**来源：广东民间工艺博物馆官网、金羊网（2019.5.17）** |

## 二、广彩（馆藏 400+ 件/套）

广彩全称「广州织金彩瓷」，以构图紧密、色彩浓艳、金碧辉煌为特色，2008 年入选第二批国家级非遗。

---

### 藏品 #5：现代广彩绘络神图瓷大碟

| 项目 | 内容 |
|------|------|
| **名称** | 广彩绘络神图瓷大碟 |
| **年代** | 现代（20 世纪中后期） |
| **尺寸** | 直径 50 cm |
| **材质/工艺** | 白瓷胎，釉上彩绘，金线勾勒（织金工艺） |
| **来源出处** | 广东民间工艺博物馆馆藏，为该馆广彩代表性展品 |
| **历史背景** | 广彩始于清代康雍之间，盛于乾隆、嘉庆年间，是专门为外销而生产的釉上彩绘瓷器品种。「络神」即洛神，题材取自曹植《洛神赋》，是广彩中常见的神话题材 |
| **艺术特色** | 构图紧密繁复，色彩浓艳，金碧辉煌，体现了广彩「织金」的典型风格——犹如「万缕金丝织白玉」 |

### 藏品 #6：清乾隆绿地开光绘人物双耳花瓶

| 项目 | 内容 |
|------|------|
| **名称** | 清乾隆绿地开光绘人物双耳花瓶 |
| **年代** | 清乾隆年间（1736–1795） |
| **尺寸** | 不详 |
| **材质/工艺** | 景德镇白瓷胎，广州加彩（广彩）；绿地开光，双耳造型 |
| **来源出处** | 广东民间工艺博物馆馆藏。图片见于广东省情网（dfz.gd.gov.cn）作为广彩代表性器物介绍 |
| **历史背景** | 广彩不生产瓷胎，瓷胎多来自景德镇，运至广州后在河南（今海珠区）一带的彩绘作坊加彩，再经十三行外销至欧洲。乾隆时期是广彩发展的鼎盛期，欧洲王室贵族争相订购「式多奇巧、岁无定样」的广彩瓷 |
| **相关故事** | 广彩的生产流程包括：设计图原稿→挑选瓷胎→配制颜料→彩绘→装炉烘烧。传统工具有枕箱、撬棒、令圈笔、水盅、擂色碗等。广州十三行一带曾有上千家专营外销品的店铺，数十万匠人从事相关生产。**来源：广东省情网、人民网（2014.12.20）** |

## 三、广州象牙雕刻（馆藏 200+ 件/套）

广州牙雕以象牙球、象牙船、象牙微雕闻名天下，清代曾为宫廷贡品和外销精品。

---

### 藏品 #8：1992 年象牙雕「龙的传人」54 层象牙球

| 项目 | 内容 |
|------|------|
| **名称** | 象牙雕「龙的传人」54 层象牙球 |
| **年代** | 1992 年 |
| **作者** | 大新象牙工艺厂出品（具体作者待考证，该厂名师包括李定宁等） |
| **尺寸** | 宽 57 cm，高 88 cm |
| **材质/工艺** | 整块象牙镂空雕刻成 54 层活动花球，每层厚薄匀实，层层皆能转动；球面刻有精美龙纹图案 |
| **来源出处** | 广州市大新象牙工艺厂捐赠/征集入藏；广东民间工艺博物馆馆藏。**来源：广州轻工集团官网（gzlig.com）、今日头条文物栏目（2024.10.12）、广东民间工艺博物馆馆藏数据库** |
| **历史背景** | 象牙球是广州牙雕最富特色的作品，其独到之处在于将一块完整牙料巧妙地镂空成一层套一层的通雕活动花球。清代象牙球仅能雕至 3 层，至清末民初发展到 25 层以上。1915 年，翁昭、梁雄制作的 25 层镂空象牙球在巴拿马万国博览会上获得金奖。**来源：中国新闻网（2014.8.5）** |
| **相关故事** | 建国后，大新象牙工艺厂的多件牙雕珍品被各大博物馆收藏：28 层象牙球「友谊第一」藏于北京中国工艺美术馆珍宝馆；巨型象牙舫「双凤朝阳」及镂通雕「撒网船」亦藏于北京；11 层牙船「孔雀舫」、「福禄寿」大花篮等 70 多件藏于广东民间工艺博物馆和广州博物馆。**来源：广州轻工集团官网** |

### 藏品 #9：清代象牙雕龙船（广州外销牙雕代表）

| 项目 | 内容 |
|------|------|
| **名称** | 象牙镂空雕龙船摆件 |
| **年代** | 清同治年间（1862–1874） |
| **尺寸** | 不详（类似龙船作品一般长 30–80 cm 不等） |
| **材质/工艺** | 象牙镂雕、浮雕、圆雕结合；雕刻者需逐层雕刻，再将各构件以榫卯结构镶嵌；门窗开合自如 |
| **来源出处** | 广州博物馆藏有一件清同治象牙镂空雕龙船，据记载为同治时期进贡庆贺慈禧寿辰所用。广东民间工艺博物馆亦藏有同类象牙龙船 |
| **历史背景** | 清代广州牙雕作坊集中在大德路与惠福西路之间的象牙街、象牙巷一带。道光年间已有牙雕行会，鸦片战争后分为「贡品行」（名「慎玉堂」）和「洋行」——贡品行多出品贡品和出口精品，洋行则面向一般外销。**来源：中国新闻网（2014.8.5）** |
| **相关故事** | 清康熙年间实行「一口通商」后，广州成为唯一的对外通商口岸，象牙原料大量进口，广州牙雕产业进入鼎盛期。牙雕龙船是当时最受欢迎的出口品类之一，欧洲贵族将其视为东方珍奇。**来源：广州轻工集团官网** |

| 项目 | 内容 |
