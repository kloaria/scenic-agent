## 八、潮州木雕（馆藏 600+ 件/套）

潮州木雕为首批国家级非遗，与东阳木雕、黄杨木雕、龙眼木雕并称中国四大木雕。

---

### 藏品 #21：潮州金漆木雕神亭（妈祖游神用）

| 项目 | 内容 |
|------|------|
| **名称** | 潮州金漆木雕神亭 |
| **年代** | 清代（具体年代待考） |
| **尺寸** | 大体量（具体数据待博物馆公布） |
| **材质/工艺** | 樟木（推测），运用浮雕、通雕、圆雕、沉雕等多种技法精雕细刻，髹漆贴金，富丽堂皇。整体结构由上下两层及基座组成 |
| **画面题材** | 主体纹饰取材自《封神演义》等神话故事。上层为重檐歇山式屋面（古建筑中等级很高的形制），屋顶分两重檐——上檐匾额刻「圣旨」，下檐匾额刻「恩光」；下层大殿殿门有「海国慈航」匾额，两侧金柱悬挂对联「圣泽覃敷民熙物阜，慈光普照浪静波平」（楷书）；殿内设有金漆描金画山水围屏，围屏前留空间安放神像 |
| **来源出处** | 广东民间工艺博物馆馆藏，在陈家祠聚贤堂展出。**来源：搜狐文化（2021.2.20）「潮州金漆木雕神亭」专文** |
| **历史背景** | 潮汕地区临海，人们普遍崇拜海神妈祖（天后）。每年农历三月廿三妈祖诞，潮汕百姓举行隆重的「游神赛会」——由德高望重的长者将妈祖神像从庙中请出，安放在神轿或神亭中，由青壮年抬着沿街巡游，各家各户摆香案迎候祭拜并燃放鞭炮，祈求海上平安 |
| **相关故事** | 这座神亭正是妈祖诞游神时安放妈祖神位之用。它不是轿子（不能抬人），也不是神龛（不放牌位），而是专门的「接神」神器。从匾额「海国慈航」和对联「浪静波平」等内容可以明确断定其与妈祖信仰的直接关联。该神亭在陈家祠聚贤堂长期展出，是反映潮汕妈祖信仰与游神赛会民俗活动的珍贵实物。**来源同上** |
| **争议/待考** | 有资料称其为「大神亭」或「龙纹大神亭」，具体入藏时间和征集来源待博物馆进一步公布 |

### 藏品 #22：清光绪潮州金漆木雕博古花鸟纹神椟

| 项目 | 内容 |
|------|------|
| **名称** | 清光绪潮州金漆木雕博古花鸟纹神椟 |
| **年代** | 清光绪年间（1875–1908） |
| **尺寸** | 高 47.5 cm，宽 38 cm |
| **材质/工艺** | 木质，金漆木雕，含浮雕、镂通雕等技法；题材为博古器物与花鸟组合 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：网易「新一级馆巡礼」（2017.2.12）** |
| **历史背景** | 「神椟」是潮汕民间供奉祖先神位的小型神器，形制较大者称「神龛」，较小者俗称「椟仔」。金漆木雕是潮州木雕中最常见、最讲究的装饰形式——作品经精雕细琢后贴上纯金箔，显得金碧辉煌。**来源：微博@三多周（广东省博物馆大神龛介绍）** |
| **文化关联** | 潮州木雕主要应用于建筑装饰、神器装饰、家具装饰、案头装饰四大领域。神椟属于神器装饰，是潮汕宗族文化和祖先崇拜的重要物质载体 |

### 藏品 #23：潮州金漆木雕大神龛（神亭体系参照物）

| 项目 | 内容 |
|------|------|
| **名称** | 清/民国金漆木雕大神龛（广东省博物馆藏同类器物参考） |
| **年代** | 民国二十四年（1935 年） |
| **尺寸** | 高 330 cm，宽 231 cm，深 145 cm（广东省博物馆所藏） |
| **来源出处** | 广东省博物馆藏。上世紀 50 年代从民间征集而来。根据神龛门上金漆画的落款推断，制作于 1935 年，在一座叫作「贻榖祠」的祠堂内制作。**来源：微博@三多周、今日头条** |
| **关联说明** | 广东省博物馆这件是目前已知最大的一件潮州金漆木雕神龛，其工艺和题材可为理解广东民间工艺博物馆同类藏品提供参照。神龛上刻画的内容极其丰富：梅花鹿和仙鹤寓意官运亨通和长寿，喜鹊飞上梅花梢寓意喜上眉梢，以木为纸、化木成金，采用多层次镂通雕、密而不乱。**来源：今日头条「每日一宝」专栏** |

涵盖潮汕和佛山两大剪纸流派，多为建国后作品。

---

### 藏品 #24：现代潮汕许文进作铜衬「西厢记·十里长亭」剪纸

| 项目 | 内容 |
|------|------|
| **名称** | 潮汕铜衬剪纸《西厢记·十里长亭》 |
| **年代** | 现代（约 20 世纪中后期） |
| **作者** | 许文进（潮汕剪纸艺人） |
| **尺寸** | 长 38.5 cm，宽 36 cm |
| **材质/工艺** | 铜衬剪纸——以铜箔为衬底，上贴剪纸图案，是潮汕剪纸中的特色品种 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：网易「新一级馆巡礼」（2017.2.12）** |
| **历史背景** | 潮汕剪纸与佛山剪纸并称广东两大剪纸流派。潮汕剪纸以纤细秀丽、精巧多变著称，常用于岁时节令、婚丧嫁娶等民俗活动中，品种包括礼品花、供品花、窗花、灯花等。「铜衬」是潮汕剪纸的独特工艺，以金属箔衬底增加了作品的华丽感和耐久性 |
| **题材故事** | 《西厢记·十里长亭》是元杂剧《西厢记》中最著名的送别场景，张生赴京赶考，崔莺莺在十里长亭为他送行。这一题材在民间艺术中广为流传，剪纸艺人在方寸之间再现了「碧云天，黄花地，西风紧，北雁南飞」的经典情景 |

## 十、潮州大吴泥塑（馆藏 30+ 件/套）

大吴泥塑起源于南宋末年，与天津「泥人张」、无锡惠山泥人并称中国三大泥塑。

---

### 藏品 #25：1960 年代潮州大吴泥塑「王茂生进酒」摆件

| 项目 | 内容 |
|------|------|
| **名称** | 潮州大吴泥塑《王茂生进酒》人物组合摆件 |
| **年代** | 1960 年代 |
| **尺寸** | 左件高 27 cm，右件高 24.5 cm |
| **材质/工艺** | 泥土捏塑，采用雕、塑、捏、贴、刻、印、彩等多种技法制成；人物造型为戏剧故事组合 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：网易「新一级馆巡礼」（2017.2.12）** |
| **历史背景** | 大吴泥塑因主要分布在潮州市潮安县浮洋镇大吴村而得名，又称「浮洋泥塑」「翁仔屏」「大吴安仔」。据史料记载，南宋末年始祖吴静山自福建漳浦携眷到大吴定居后，以塑造泥玩具为生，其技艺世代相传。清代光绪至民国初年发展到鼎盛，形成绚丽光亮、造型栩栩如生的独特风格。2008 年入选第二批国家级非遗。**来源：中国非物质文化遗产网、百度百科** |
| **题材故事** | 「王茂生进酒」是一出潮剧传统剧目。王茂生是个穷汉，为给义兄薛仁贵（已贵为平辽王）贺寿，以水代酒前往王府，演绎了一段「君子之交淡如水」的感人故事。泥塑捕捉了戏剧中人物互动的精彩瞬间。**来源：搜狐文化（2021.11.27）** |

## 十一、潮州枫溪瓷塑（馆藏 600+ 件/套）

枫溪是潮州陶瓷的核心产区，以通花瓷、瓷塑人物闻名。

---

### 藏品 #26：1971 年枫溪雕白玉寄菊通花瓶

| 项目 | 内容 |
|------|------|
| **名称** | 枫溪雕白玉寄菊通花瓶 |
| **年代** | 1971 年 |
| **作者** | 枫溪瓷艺家（具体作者待考证，馆藏枫溪瓷名家包括陈钟鸣、林鸿禧、吴金福、王龙才、叶竹青等） |
| **尺寸** | 口径 7 cm，高 35 cm |
| **材质/工艺** | 白瓷胎，通花镂雕工艺——在瓷坯体上雕通几何图纹或花卉图案，经高温烧成后再人工彩绘装饰，最后经烤花窑烧制。菊花为主题纹饰 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：网易「新一级馆巡礼」（2017.2.12）** |
| **历史背景** | 通花瓷是枫溪瓷塑的标志性品种。通花装饰多以镂空几何纹样为底纹，底纹多为四方连续图案，便于雕刻和连接。1978 年，枫溪制作的 1.3 米高通花瓶曾作为国礼赠送给朝鲜领导人金日成，轰动一时。**来源：百度百科「通花瓶」** |
| **作者关联** | 陈钟鸣（1936–2008），潮州人，1959 年毕业于景德镇陶瓷学院，中国工艺美术大师，擅长陶瓷仕女雕塑，以「清、新、秀、雅」的风格著称。他是枫溪瓷塑的代表性人物。**来源：广东省文化馆非遗传承人档案** |

## 十二、馆藏来源总脉络——那些不应被遗忘的捐赠者

> 广东民间工艺博物馆的馆藏构建，离不开一代又一代捐赠者的无私奉献。以下梳理最重要的捐赠脉络。

---

### 杨铨（1898–1967）——馆藏奠基人

| 项目 | 内容 |
|------|------|
| **身份** | 祖籍广东鹤山，世居香港，海内外知名的文物鉴藏家 |
| **捐赠时间** | 1959–1964 年，分八批运回内地 |
| **捐赠总量** | **5,542 件（套）**文物捐献给广州市政府，是新中国成立初期我国政府接受的最大规模的文物捐赠 |
| **捐赠内容** | 其中由广东民间工艺博物馆接收编藏的有：古陶瓷 3,390 件、铜器 231 件、玉器 184 件、竹雕 244 件、木雕 26 件、古墨 620 件及一批文物资料 |
| **文物价值** | 涵盖新石器时代至民国各时期，包括青瓷、黑白瓷、青花瓷、石湾陶、彩陶、彩瓷、玉雕、铜镜、古墨、竹雕等，**其中大量为国家级珍贵文物** |
| **感人故事** | 杨铨年少时移居香港，痛心于祖国文物因盗卖而大量散失海外，立志穷毕生之力收藏保护华夏文物。他克服重重困难（当时内地与香港之间交通不便、政治环境复杂），将毕生珍藏分八批运回祖国。**来源：金羊网（2019.5.17）、昆明信息港（2025.8.11）** |
| **博物馆纪念** | 2019 年广东民间工艺博物馆建馆 60 周年之际，举办《盛德宜扬：杨铨先生捐献文物精品展》致敬 |

### 商承祚（1902–1991）——学者型收藏家

| 项目 | 内容 |
|------|------|
| **身份** | 字锡永，号驽刚、契斋，广东番禺人，古文字学家、考古学家、金石篆刻家，中山大学教授 |
| **捐赠内容** | 石湾陶、玉器等珍贵文物（含明代兰亭砚等端砚精品）。晚年及去世后，其哲嗣将所收藏的近 **1,200 件**珍贵文物无偿捐献给故宫博物院、中国历史博物馆、广东省博物馆、湖南博物馆、广东民间工艺博物馆等多家机构 |
