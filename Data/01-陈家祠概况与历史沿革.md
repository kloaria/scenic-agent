# 01 - 陈家祠概况与历史沿革

---

## 一、基本概况

陈家祠，正式名称为「陈氏书院」，俗称陈家祠，位于广东省广州市荔湾区中山七路恩龙里34号。它是现存规模最大的广府传统建筑之一，也是中国现存规模最大、保存最完好、装饰最精美的祠堂式建筑，被誉为**"岭南建筑艺术的明珠"**。

陈家祠筹建于清光绪十四年（1888年），清光绪十九年（1893年）落成，是广东省各地陈氏宗族共同捐资兴建的"合族祠"。其建立主要为参与捐资的陈氏宗族子弟赴省城备考科举、候任、交纳赋税、诉讼等事务提供临时居所。

陈家祠集岭南建筑工艺装饰之大成，几乎全部堂、院、廊、厅、门、窗、栏、壁、屋脊、架梁都展示了岭南建筑的"三雕二塑一铸一画"——即木雕、砖雕、石雕、陶塑、灰塑、铜铁铸及彩绘壁画等建筑装饰的高超技艺。

## 三、历史沿革（大事记）

| "文化大革命"期间 | 被迫停展闭馆，广州新华印刷厂以印刷毛主席著作为由进驻，造成严重损坏 |

| 1995年10月 | 广州市第三十二中学拆除建在前院的教学楼，归还前院 |
| 1996年 | 广州复印机厂依法迁出后院和东院 |
| 2002年 | 以"古祠留芳"之名入选**"新世纪羊城八景"** |

| 2008年 | 被评为**国家AAAA级旅游景区** |

| 2010年10月 | 前广场地面降回历史标高；复原石狮子基座；重竖旗杆 |

| 2022年 | 建成"陈家祠文物预防性保护智能监测平台" |
| 2025年-2026年 | 第8次灰塑保养维护工程，维护面积达1,285平方米 |

## 四、名称由来——为什么叫"陈氏书院"而非"陈家祠堂"？

陈家祠的正门匾额上写着"陈氏书院"四个大字，但它本质上是一座祠堂，并非供子弟读书的书院。这背后有一段历史：

自清代乾隆中期开始，官府认为合族祠"把持讼事，挟众抗官"，遂发起一次又一次大规模的禁祠行动，广州城内许多合族祠因此被禁。于是各姓合族祠纷纷改名为"书院""试馆""书室"，以规避禁令。陈家祠被题匾为"陈氏书院"，正是出于这个原因——**挂书院之名，行祠堂之实**。

## 五、地位与荣誉

1. **全国重点文物保护单位**（1988年，第三批）
   - 编号：3-2-85-33，由中华人民共和国国务院公布

2. **新世纪羊城八景"古祠留芳"**（2002年）
   - 入选八景之一，被誉为"广州文化名片"

3. **国家AAAA级旅游景区**（2008年）
   - 以陈家祠为馆址的广东民间工艺博物馆获评

4. **国家一级博物馆**（2017年）
   - 由中国博物馆协会公布

5. **广州市文明旅游示范单位**（2022年，第一批）

## 六、郭沫若题诗

1959年，郭沫若先生参观陈家祠后，被其精湛的建筑工艺所震撼，即兴赋诗一首：

> **天工人可代，人工天不如。**
> **果然造世界，胜读十年书。**

这首诗已成为称赞陈家祠的经典名句，广为传颂。

---

## 七、地理位置与周边

陈家祠位于广州市老城区（荔湾区），中山七路恩龙里34号。其选址在"原清代羊城八景之一的浮丘丹井之侧"（据《南海县志》记载，浮丘山在陈家祠之右）。

周边交通便利，广州地铁1号线设有"陈家祠站"，出站即到。
