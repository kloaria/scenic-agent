# 馆藏精品档案（中篇）——广绣 · 潮绣 · 端砚 · 珐琅 · 外销扇

> 资料来源均标注于每件藏品末尾。所有信息来源于博物馆官方、权威媒体及学术文章。

## 四、广绣与潮绣（馆藏广绣 300+ 件/套，潮绣 200+ 件/套）

广绣与潮绣合称「粤绣」，是中国四大名绣之一，2006 年入选第一批国家级非遗。

---

### 藏品 #11：清末广州钉金绣龙凤练雀纹方补霞帔

| 项目 | 内容 |
|------|------|
| **名称** | 清末广州钉金绣龙凤练雀纹方补霞帔 |
| **年代** | 清末（约 19 世纪末—20 世纪初） |
| **尺寸** | 长 82 cm，宽 70 cm |
| **材质/工艺** | 钉金绣（又称盘金绣、金银线绣），以金线、银线为主要绣线，在缎面上盘绕钉固 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：网易「新一级馆巡礼」（2017.2.12）、知乎「博物馆 Vol.151」** |
| **历史背景** | 「霞帔」是古代命妇（有封号的官员妻子）的礼服配饰，从肩上绕过，象征身份尊贵。方补即官服前胸后背的补子，以不同禽鸟纹样区分品级。练雀（即绶带鸟）是清代文官九品的补子纹样。广绣（钉金绣）工艺历史悠久，1957 年广州发现的明正德年间戴缙夫妇墓中即出土了金线绣衣裙，证明广州金线绣至少有 500 年以上历史。**来源：搜狐文化（2021.11.7）** |
| **相关故事** | 钉金绣是广绣三大技术绣种之一（另外两种为丝绒绣和珠绣）。绣制时需将金线盘绕在缎面上，用丝线钉固，工艺复杂，一件霞帔往往需数月甚至更长时间完成。该藏品在博物馆常设《粤绣》展厅中长期展出，是了解清代命妇服饰制度和广绣顶级工艺的重要实物。 |

### 藏品 #12：广绣「万缕金丝」精品系列

| 项目 | 内容 |
|------|------|
| **名称** | 广绣精品多件（具体单件名称需实地确认） |
| **年代** | 清代至现代 |
| **来源出处** | 广东民间工艺博物馆馆藏。该馆于 2025 年 11 月至 2026 年 7 月在前东斋展厅举办「万缕金丝——馆藏广绣精品展」，展出多件馆藏广绣精品。**来源：广东民间工艺博物馆官网展览公告** |
| **历史背景** | 广绣至今已有千年以上历史。自唐代以来，广东地区就是海上丝绸之路的重要节点，丝绸和刺绣是对外贸易的重要商品。广绣以构图饱满、色彩斑斓、针法多变著称，与苏绣、湘绣、蜀绣并称中国四大名绣 |
| **相关工艺** | 广绣针法包括直针、续针、捆咬针、铺针、洒插针、扭针等数十种。广绣艺人能将一根丝线劈成 16 股甚至更细，绣出极其精细的图案 |

### 藏品 #13：潮绣藏品系列

| 项目 | 内容 |
|------|------|
| **名称** | 潮绣系列藏品（包括传统潮绣、抽纱刺绣、通锦绣等） |
| **年代** | 近代至现代 |
| **收藏数量** | 200 余件/套 |
| **来源出处** | 广东民间工艺博物馆馆藏。来源同上——「博物馆 Vol.151」、网易「新一级馆巡礼」 |
| **历史背景** | 潮绣是粤绣的重要分支，以潮州为中心，以金线绣、绒绣为主要特色。潮绣构图饱满均衡、色彩浓烈、立体感强，尤以「垫高绣」（在绣面上垫棉花等填充物再绣）独树一帜。抽纱刺绣则是潮汕地区特有的舶来技艺融合本土工艺的产物 |
| **相关故事** | 潮绣与潮州木雕、潮州陶瓷、潮剧等一起构成了潮汕文化的重要工艺体系。该馆 2023 年元旦至 6 月曾举办广州象牙雕刻与潮绣联合精品展，从馆藏中精选数十件精品展出。**来源：广东民间工艺博物馆官网（2023.1.3）** |

## 五、端砚（馆藏 200+ 方）

2023 年博物馆首次系统展出端砚，选取 34 件（套）精品，涵盖宋元至近现代。

---

### 藏品 #14：宋元蝉形砚

| 项目 | 内容 |
|------|------|
| **名称** | 蝉形砚 |
| **年代** | 宋元之间（约 1206–1279） |
| **尺寸** | 长 21.8 cm，宽 13.9 cm，厚 3.1 cm |
| **材质/工艺** | 端石（具体石坑待考），砚体仿蝉造型；砚额正中有一石眼，绕石眼深雕出蝉的大眼作砚池；下端修长蝉身为砚堂；头部往下边线曲折有致为蝉翼；砚背弧形，首部枕式落地，下方对称出乳足 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：新快报（2023.6.25）、广州日报大洋网（2025.2.17）** |
| **历史背景** | 端砚自唐代采石制作以来就成为名砚，以「贮水不耗、发墨不损、严寒不冰」著称。宋代端砚开始实用与欣赏并重，砚式从简单趋向多样化，蝉形砚是宋砚中的经典样式 |
| **文化寓意** | 古人认为蝉居枝头只吸干净露水、不食人间烟火，象征高洁人品。传统文人常借蝉自喻，蝉形砚因此成为文人雅士心爱之物。**来源：广州日报大洋网（2025.2.17）** |

---

### 藏品 #15：明代兰亭砚（商承祚捐赠）

| 项目 | 内容 |
|------|------|
| **名称** | 兰亭砚 |
| **年代** | 明代（1368–1644） |
| **尺寸** | 长 23.5 cm，宽 14.5 cm，高 6.5 cm |
| **材质/工艺** | 端石，砚面以兰亭雅集为主题雕刻 |
| **来源出处** | **商承祚捐赠**。商承祚（1902–1991），字锡永，广东番禺人，古文字学家、考古学家、金石篆刻家，中山大学教授。他一生收藏大量珍贵文物，晚年及去世后其哲嗣将近 1,200 件文物无偿捐献给故宫博物院、中国国家博物馆、广东省博物馆、广东民间工艺博物馆等。**来源：新快报（2023.6.25）、光明网（2024.2.2）** |
| **历史背景** | 兰亭砚以王羲之《兰亭集序》典故为题材，是明清端砚中的经典主题。明代端砚实用与欣赏并重，雕刻趋于精细。商承祚捐赠的这方兰亭砚见证了民国以来学者收藏家将私人珍藏化私为公的高尚情怀 |

### 藏品 #16：明代二甲传胪砚

| 项目 | 内容 |
|------|------|
| **名称** | 二甲传胪砚 |
| **年代** | 明代（1368–1644） |
| **材质/工艺** | 宋坑端石，长方形，砚体厚重；砚面下开砚堂近圆，有数石眼；上端深凿一洼为砚池，墨锈深厚，池中栖息两蟹，边饰芦荻；砚背挖空，四隅有足，一边浅雕一斜伸如意状灵芝，中间篆文印章「发解传庐」 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：广州日报大洋网（2025.2.17）** |
| **文化寓意** | 「二甲传胪」即科举殿试二甲第一名，寓意金榜题名、仕途高升。螃蟹（谐音「甲」）与芦荻（谐音「胪」）的组合是明清工艺中常见的吉祥图案，寄托了读书人科举得中的美好愿望。此砚为陈家祠「合族祠」为应试子弟提供居所的历史背景增添了注脚 |

### 藏品 #17：清中期云月砚（「吴门顾二娘制」款）

| 项目 | 内容 |
|------|------|
| **名称** | 云月砚（「吴门顾二娘制」款） |
| **年代** | 清中期（约 18 世纪） |
| **材质/工艺** | 黄蚓矢端石，色青黑泛紫；砚面右上方凿月形凹池，雕流云掩映；砚背浅浮雕江上行舟图 |
| **款识** | 右下角行书款「吴门顾二娘制」；一侧镌「得少佳趣」，篆书印「黄绢幼妇」；另一侧篆书印「十砚主人」「黄任珍藏」 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：广州日报大洋网（2025.2.17）** |
| **历史背景** | 清早期制砚以顾二娘名气最大，玩砚则以黄任（黄莘田）名声最响。「顾琢黄铭」之砚合二者之名望，声誉更隆，故后世多有仿冒。**馆方专家指出：此砚雕工圆润，但是否为顾二娘真品尚待考量。**来源同上 |
| **相关故事** | 顾二娘是清代雍正、乾隆年间的女制砚名家，苏州人，其制砚以「古雅而兼华美」著称，一件真品价值连城。黄任（1683–1768）号莘田、十砚主人，福建永福人，康熙举人，以收藏端砚闻名，自称「十砚斋」。这方砚台集「顾琢黄铭」于一身——无论真伪，都反映了端砚收藏史上的一段佳话。 |

## 六、广州珐琅（馆藏 150+ 件/套）

以广州生产的珐琅器居多，既有宫廷精品也有民间作坊产品。

---

### 藏品 #19：清乾隆錾胎掐丝珐琅万寿无疆碗

| 项目 | 内容 |
|------|------|
| **名称** | 清乾隆錾胎掐丝珐琅「万寿无疆」碗 |
| **年代** | 清乾隆年间（1736–1795） |
| **尺寸** | 口径 16.7 cm，高 17.2 cm |
| **材质/工艺** | 铜胎，结合錾胎珐琅与掐丝珐琅两种工艺；碗内壁錾刻「万」「寿」「无」「疆」四字篆书吉祥语；碗底镌「子孙永宝」四字篆书款识 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：网易「新一级馆巡礼」（2017.2.12）、百度百科「铜掐丝珐琅万寿无疆碗」** |
| **历史背景** | 广州珐琅（广珐琅）在清代康雍乾时期达到鼎盛，广州工匠常被征召入宫为皇家制作珐琅器。乾隆时期宫廷珐琅器的底款常见「子孙永宝」等吉语，此碗具有典型的乾隆时期宫廷艺术特征。制作工艺以画珐琅为主，兼有掐丝珐琅、錾胎珐琅 |
| **工艺辨析** | 掐丝珐琅（景泰蓝）在胎体表面用金属丝围出各区域然后填釉料；錾胎珐琅是在金属胎体上凿小坑再填釉料；画珐琅则摆脱了「丝」和「坑」的限制，可以直接在胎体上彩绘。此碗结合了两种工艺，技法精湛。**来源：网易号（2022.9.11）** |

## 七、广州外销扇（馆藏近 60 件/套）

16–19 世纪从广州出口到欧洲的各式扇子，是东西方文化交汇的典型见证。

---

### 藏品 #20：清象牙纸面彩绘人物庭园图折扇

| 项目 | 内容 |
|------|------|
| **名称** | 清象牙纸面彩绘人物庭园图折扇 |
| **年代** | 清代（约 18–19 世纪） |
| **尺寸** | 长 27.7 cm，展幅宽 50 cm |
| **材质/工艺** | 象牙扇骨，纸面彩绘。扇面绘有人物庭园场景，融合中国传统工笔与西方明暗透视技法 |
| **来源出处** | 广东民间工艺博物馆馆藏。**来源：网易「新一级馆巡礼」（2017.2.12）** |
| **历史背景** | 16 世纪中国折扇开始传入欧洲，大受欢迎。广州是外销扇的制造中心，清道光年间（1822 年）广州十三行一带有上千余家专营外销商品的店铺。外销扇材质多样，包括象牙、玳瑁、黑漆描金、银、贝壳、纸、丝、檀香木等。**来源：新浪收藏（2017.4.13）、广东省博物馆官网** |
| **相关故事** | 广东民间工艺博物馆曾联合英国维多利亚与阿尔伯特博物馆、格林威治扇子博物馆、剑桥大学菲茨威廉博物馆举办「扇子上的东方与西方：18–19 世纪的中西成扇」展，足见其外销扇收藏的国际认可度。**来源：孙中山大元帅府纪念馆官网（2017.12.4）** |
| **其他馆藏来源** | 广州市内对外销扇收藏较多的还有广东省博物馆和广州十三行博物馆。广东省博物馆研究馆员白芳指出，广东省博的外销扇收藏在国内名列前茅。**来源：新浪收藏（2017.4.13）** |
