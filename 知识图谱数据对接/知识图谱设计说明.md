# 知识图谱设计说明

> **数据来源**：基于陈家祠知识库清洗结果，参照用户提供的知识图谱设计参考规范编制

---

## 一、设计原则

### 1.1 实体与属性的区分

- **实体**：独立存在、可以和其他事物产生关联的对象，可以被连线、可以被推理、可以被推荐、可以构成路线
- **属性**：依附实体的静态描述信息，不能单独存在、不能建立关系，只用于展示、筛选、检索，不做图谱节点
- **长文本**：所有长文本介绍、详细讲解、故事文案 → 全部进入向量知识库，不进图谱

### 1.2 双向输出原则

每条原始数据同时处理为两份输出：
- **向量库语料**：长文本叙述，保留完整内容，用于语义检索
- **图谱实体**：结构化实体+关系，用于图谱推理和关联查询

## 四、实体间关系（15种）

| 序号 | 关系类型 | 方向 | 说明 |
|:---|:---|:---|:---|
| 1 | 位于 | 展厅/景点/设施/活动 → 城市/展厅 | 空间归属关系 |
| 2 | 展示于 | 展品 → 展厅 | 展品与展厅的归属 |
| 3 | 属于 | 展品 → 器物类别/文化主题 | 分类归属 |
| 4 | 创作于 | 展品 → 朝代时期 | 年代归属 |
| 5 | 出土于 | 展品 → 景点/城市 | 出土地点 |
| 6 | 与人物相关 | 展品/事件 → 历史人物 | 人物关联 |
| 7 | 与事件相关 | 展品/人物 → 历史事件 | 事件关联 |
| 8 | 同一时期 | 展品↔展品、事件↔事件 | 双向关系 |
| 9 | 同一主题 | 展品↔展品 | 双向关系 |
| 10 | 相邻 | 展厅↔展厅 | 空间相邻 |
| 11 | 推荐参观 | 展品↔展品 | 智能推荐核心 |
| 12 | 路线包含 | 游览路线 → 展品/展厅 | 路线组成 |
| 13 | 下一站 | 动态推理关系 | 不静态入库 |
| 14 | 附近设施 | 展厅/景点 → 场馆设施 | 设施关联 |
| 15 | 适合面向 | 展品/路线 → 人群标签 | 推荐筛选核心 |
| 16 | 举办于 | 活动 → 展厅/景点 | 活动场地 |

## 五、全局字段规范

| 字段名 | 类型 | 必填 | 说明 |

| id | string | 是 | 实体唯一标识符（如entity_001） |
| name | string | 是 | 实体名称 |
| type | string | 是 | 实体类型 |
| tags | array | 否 | 标签数组 |
| properties | object | 是 | 属性对象 |
| description | text | 是 | 长文本描述 |
| images | array | 是 | 关联图片URL数组，无图片时为空数组 |
| source | string | 是 | 数据来源，须标注为外部权威来源 |
